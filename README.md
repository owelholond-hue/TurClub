# Туристический клуб «Вершина»

Одностраничный адаптивный сайт туристического клуба с каталогом туров,
фильтрацией, анимированными счётчиками, валидацией форм, переключением
тёмной/светлой темы и модальным окном.

## 🔗 Демо

**Netlify:** https://vershina-club.netlify.app

## 🛠 Технологии

- HTML5 (семантическая вёрстка)
- CSS3 (Flexbox, Grid, CSS-переменные, медиазапросы)
- Vanilla JavaScript (ES6+, `addEventListener`, `IntersectionObserver`)
- Netlify (CI/CD из GitHub)

## ✨ Функционал

- Адаптивная вёрстка (мобильные и десктопные экраны)
- Бургер-меню на мобильных
- Переключение светлой/тёмной темы (сохраняется в `localStorage`)
- Фильтрация туров по категориям
- Анимированный счётчик статистики при прокрутке
- Валидация формы обратной связи и формы в модальном окне
- Модальное окно «Заказать звонок»
- Toast-уведомления вместо `alert()`

## 🚀 Запуск локально

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/tourism-club.git
   cd tourism-club
   ```

2. Откройте проект одним из способов:

   **Вариант A — просто открыть файл:**
   Откройте `index.html` двойным кликом в браузере.

   **Вариант B — локальный сервер (рекомендуется):**

   ```bash
   # Python 3
   python -m http.server 8000

   # или Node.js (если установлен)
   npx serve
   ```

   Затем перейдите по адресу `http://localhost:8000`.

## 📦 Деплой на Netlify

1. Запушьте проект в публичный репозиторий GitHub.
2. На [netlify.com](https://netlify.com)
